Frameworks & bridge

All framework-specific code lives in one small file per framework, on each side. Everything else in the phone works the same on every framework.

How the bridge works

The folder bridge/ has one file per framework in client/ and server/. Every file starts with a check like if Config.Framework == 'QBX' then, so only the one you picked does anything. Each file fills in a small Bridge table:

SideFunctionReturns
clientBridge.IsLoaded()Whether the character has spawned in.
clientBridge.GetPlayerData()Name, job, gang, cash and bank for the UI.
clientBridge.IsDead() / Bridge.IsCuffed()Booleans for the open checks.
serverBridge.GetPlayer(src){ identifier, firstname, lastname, phone, job, gang, cash, bank } or nil.
serverBridge.GetSourceByIdentifier(id)The source of an online character, or nil.
serverBridge.GetSourceByPhone(number)The source of an online player with that framework phone number, or nil.
serverBridge.MoveMoney(src, account, amount, reason)account is 'cash' or 'bank', negative takes money away. Must return false if the player can't afford it.
serverBridge.GetVehicles(src, identifier)The character's vehicles: { id, model, plate, garage, stored, fuel, engine, body, … }[].

Every place that uses the bridge checks the function exists first, so a partial bridge still works: a missing GetVehicles just means an empty Garage.

Adding another framework

  1. Copy the closest bridge

    Copy bridge/client/qbx.lua and bridge/server/qbx.lua to, say, mycore.lua in the same folders.

  2. Change the guard 
    if Config.Framework == 'MYCORE' then
    Bridge = Bridge or {}
    -- ...
end
  3. Fill in the functions

    Implement the table above with your framework's API. Start with GetPlayer, IsLoaded and MoveMoney: that's enough for everything except the Garage.

  4. Select it

    Set Config.Framework = 'MYCORE'. The manifest already loads every file in bridge/.

Closing the phone on logout

Trigger royal-phone:client:playerUnloaded on the client when a character logs out, and the phone closes cleanly. The QBX, ESX and ND bridges already do this; ox_core and standalone don't yet.
