Royal Phone

A fast, good-looking phone for FiveM. Calls with real voice, texts and group chats, a social network, banking, contracts you can sign, SIM cards you can steal, and an API that lets any resource add its own app.

What you get

Calls with real voice

pma-voice call channels, ringing, missed calls and a call log. Answer with a key while driving.

Messages & groups

Texts, group chats, photos, voice notes, shared locations and emoji. Offline players get the backlog.

SIM cards

The number and everything on it belong to the SIM. Steal someone's card and read their messages.

11 built-in apps

Phone, Messages, Contacts, Camera, Gallery, Bank, Garage, Documents, Lifeinvader, Calculator, Settings.

Your own apps

Any resource can add an app with plain HTML. Template, SDK and UI kit included.

Walk and drive with it open

Movement stays with the game while the phone is up, and typing never moves your character.

At a glance

  • Drop-in. The interface ships pre-built and the database sets itself up on first start. No SQL to import, no build step.
  • Works with your framework. QBX, ESX, ox_core, ND Core or standalone, through one small bridge file each.
  • Light on the server. No polling. Data is read when the phone opens, and changes are pushed only to the phones that need them.
  • Secure by default. The server decides who a request belongs to. A client can't post as someone else, read another player's thread or push contacts into a stranger's phone.
  • Made to be extended. Server exports that accept a player or a phone number, events for calls and messages, per-app storage, and a custom app system.
